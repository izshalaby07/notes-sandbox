# Notes Sandbox

A throwaway notes API for testing the AI agent team end to end: scoping, tickets, mixed-model builders, review, CI and protected `main`. No real data, so free models are fine here.

- Setup: [`docs/SETUP.md`](docs/SETUP.md), Parts C and D.
- The first slice: [`docs/specs/001-notes-crud.md`](docs/specs/001-notes-crud.md).
- Results: [`docs/pilot-log.md`](docs/pilot-log.md) and [`docs/agents/benchmark.md`](docs/agents/benchmark.md).

When the test is done, keep the log and the lessons (copy useful rules into the template's `AGENTS.md`), then archive or delete this repo.
